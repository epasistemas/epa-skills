# Proveniência (resumo)

Skills `0.2.x` incluem reescritas **sanitizadas** a partir de slugs internos (inventário, não dependência de instalação). Nomes de origem indicam linhagem apenas; direitos de redistribuição comercial exigem confirmação jurídica.

| Skill publicada | Origens indicativas (sanitizadas) |
| --------------- | --------------------------------- |
| `epa-crm-mapa`, `epa-crm-operacoes` | `epa-mapa`, `crm-knowledge-map`, `epa-browser-ops` |
| `epa-crm-visitas` | `epa-visitas-ops`, `epa-visitas-validacao`, `epa-visitas-valida-o` |
| `epa-coleta-progressiva` | `epa-coleta-conversacional` + rascunho genérico da PR |
| `whatsapp-*` | família `wa-bot-*`, `epa-wa-*`, template WhatsApp (sem anexos operacionais) |
| `drive-organizacao-documental` | receita original (não plugin) |
| `epa-crm-drive-incorporacao` | receita original estrutural CRM/Drive |

**Excluído por política:** credenciais, titular/contatos, grupos/históricos, configs de cliente, plugins gerenciados, scripts não revisados.

**Limitações:** scanner heurístico e revisão humana não garantem ausência absoluta de dados sensíveis; nenhum teste em CRM/Drive/WhatsApp real neste repositório.
